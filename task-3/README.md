# LangChain Research Agent (Task 3)

A Python AI agent built with LangChain that uses function calling to solve compound queries using external tools. It logs its reasoning step-by-step: `Thought -> Action -> Observation -> Final Answer`.

## Tools

- **`web_search`**: DuckDuckGo search for live web information.
- **`calculator`**: Evaluates math expressions using Python's `math` module.
- **`read_file`**: Reads local text files.
